# Collections

`liberusoftware/module-cms-collections` preserves the legacy Collections and
CollectionItems feature as an independently removable CMS module. It owns the
tenant-scoped persistence, published read-only Delivery API endpoints, and the
Filament collection catalogue. The package name uses Packagist's normal
`liberusoftware/module-*` convention; the repository is named
`module-cms-collections`.
